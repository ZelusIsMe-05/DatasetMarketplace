# Kế hoạch triển khai Dataset Marketplace (Backend + Smart Contract trước, Frontend sau)

Nguồn sự thật: [`DatasetMarketplace_Hackathon.md`](../DatasetMarketplace_Hackathon.md) (gọi tắt là **đề xuất**).
Tài liệu này ghi lại phân tích, thiết kế module, thứ tự phụ thuộc và **mọi chỗ lệch so với đề xuất kèm lý do**.

---

## 1. Vai trò và nghiệp vụ

| Vai trò | On-chain | Off-chain (backend) |
|---|---|---|
| Người tạo chiến dịch | Chỉ ký; relayer gửi `createCampaignWithSig` (trừ quỹ mồi + phí xử lý bằng permit), `withdrawWithSig`, `withdrawSeedWithSig` (§3 #25), `publishSnapshotWithSig` (§3 #28); vẫn tự gọi được `createCampaign`/`withdraw`/`withdrawSeed`/`publishSnapshot` | Soạn nháp chiến dịch: metadata, bộ câu mẫu, điều khoản → backend tính `promptSetHash`, `termsHash`, quy đổi VNĐ→USDC. **Chủ dữ liệu**: duyệt bản ghi vùng xám, ký công bố phiên bản dataset (§3 #28) |
| Người đóng góp | Không tự gửi giao dịch (relayer gửi `giveConsentWithSig`, `claimWithSig`, `revokeWithSig`); vẫn có thể tự gọi `claim`/`revoke` | Ví trình duyệt **hoặc** MetaMask/Core (xem §3 #22); đăng nhập Google, gắn 1 email ↔ 1 ví, ký EIP-712, nhận câu mẫu + prompt token, ghi âm, xem tiền chưa rút; sao lưu/nâng cấp ví trình duyệt bằng file keystore V3 |
| Người mua | Chỉ ký (`Buy` + permit), relayer gửi `buyWithSig` — không cần AVAX (§3 #25); vẫn tự gửi được `approve` + `buy` (CLI) | Ký thông điệp chứng minh ví → backend kiểm license on-chain → link tải có hạn |
| QC oracle | `registerContribution` | Pipeline QC, commitment có salt, đóng gói dataset, Merkle root (bản tóm tắt cho người tạo ký) |
| Nền tảng | Nhận phần còn lại + bụi làm tròn qua `withdraw`; owner đặt `setClaimFee`, `setQcOracle` | Relayer (ví nóng trả gas); việc nền tự động: đồng bộ sự kiện, tự duyệt vùng xám quá hạn, thử lại giao dịch lỗi. **Không có vai trò quản trị** (§3 #28) |

### Dữ liệu nằm ở đâu

| Dữ liệu | Blockchain | Database (SQLite hoặc PostgreSQL/Neon) | Kho riêng tư (đĩa hoặc Backblaze B2, §3 #29) |
|---|---|---|---|
| Tiền, giá, tỷ lệ chia, hạn, mục tiêu | ✓ | cache chỉ mục sự kiện | |
| `promptSetHash`, `termsHash`, `metadataURI` | ✓ | văn bản gốc | |
| Đồng thuận (thời điểm), thu hồi (`revokedAt`) | ✓ | bản ghi giao dịch relayer | |
| Commitment `keccak256(audio ‖ salt)`, số giây | ✓ | ✓ | |
| Salt 32 byte | ✗ | ✓ (xóa khi thu hồi) | |
| Audio | ✗ **không bao giờ** | đường dẫn | ✓ (xóa khi thu hồi / bị loại) |
| Email, user ↔ ví | ✗ | ✓ | |
| License | ✓ | cache sự kiện `Purchased` | |
| Phiên bản dataset | Merkle root (sự kiện `SnapshotPublished`) | manifest + proof | audio của phiên bản |

### Luồng gọi

```
CLI / Frontend ──HTTP──▶ FastAPI ──▶ services ──▶ repositories ──▶ SQLite / PostgreSQL (Neon)
                                   │            └▶ storage (audio riêng tư: đĩa hoặc Backblaze B2)
                                   ├▶ qc (Silero VAD + wav2vec2 CTC + forced_align + CER)
                                   ├▶ blockchain.client (đọc contract)
                                   ├▶ blockchain.relayer (ký + gửi tx, quản lý nonce/gas/receipt)
                                   └▶ blockchain.indexer (đọc sự kiện → DB, xử lý thu hồi tự gửi)
Người tạo / người mua ──chữ ký (EIP-712 + permit)──▶ sponsor_service ──relayer──▶ VoiceCampaigns (…WithSig, §3 #25)
CLI demo ──ví của họ──▶ VoiceCampaigns (createCampaign, approve+buy, withdraw)
```

## 2. Thứ tự phụ thuộc giữa các module

1. `contracts/` (ABI là hợp đồng giao tiếp cho mọi thứ khác) → `forge build/test`, Deploy, SeedDemo.
2. `backend/app/core` (config theo `NETWORK`, money, bảo mật token, lỗi, logging).
3. `backend/app/models` + Alembic migration → `repositories`.
4. `backend/app/blockchain` (ABI, client, EIP-712, relayer, indexer).
5. `backend/app/qc` (độc lập, chạy được bằng `python -m app.qc`).
6. `backend/app/services` (auth → campaign → consent → prompt → contribution → rewards/revoke → marketplace → dataset/snapshot → review).
7. `backend/app/api` (routers mỏng gọi services) → `main.py`.
8. `backend/cli` (gọi API + gọi contract trực tiếp cho thao tác của ví người tạo/người mua).
9. `scripts/*.bat` → demo end-to-end.
10. `frontend/` (khung Next.js, dùng lại các kiểu dữ liệu của API).
